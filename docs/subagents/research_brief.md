# v0.8.0 Research Brief

The safe claim is a bounded managed-to-native control path for one owned D3D11
workload. Win32 named shared memory is IPC, not CPU/GPU unified memory. The
manager authorizes but does not classify individual copies; native provenance
does. Logical avoided bytes are not physical-bus measurements. Performance,
external targets, CPU scheduling, RAM/VRAM residency, and presentation action
remain outside the release claim.
