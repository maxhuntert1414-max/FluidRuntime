# v0.8.0 Project Plan

1. Version native and managed control contracts together.
2. Publish and acknowledge one bounded policy in an owned target.
3. Apply at most one action after native provenance proof.
4. Fail closed on identity, ABI, event, policy, lifecycle, content, or rollback
   mismatch.
5. Harden mapping access, concurrency, detach, stale calls, and module lifetime.
6. Validate Release, Debug, WARP, RX 580, and exact CI predicates.
7. Publish as correctness evidence with no unsupported performance claim.
