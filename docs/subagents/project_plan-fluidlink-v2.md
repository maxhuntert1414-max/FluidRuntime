# FluidLink v2 Project Plan

1. Canonical contract and deterministic vectors.
2. Python v2 codec/server with isolated v1 compatibility.
3. Typed .NET codec/client/package and real cross-process probe.
4. Same-flow frame-byte evidence with fixed-point assertions.

Success requires no JSON in v2 payloads, exact cross-language bytes, fail-closed
session behavior, preserved v1 compatibility, and bounded public claims.
