# Generalized D3D12 Transfer Core Evidence v0.21.0

Recorded on 2026-08-11 with FluidRuntime 0.21.0, FluidGateway 0.67.0,
FluidLink v2 batch contract
`bf8727c22ac878ceff6dd0f462d6db5e81174737e839ecdf2e263a6f55268542`,
Windows D3D12, WARP, and an AMD Radeon RX 580 2048SP.

## Result

Version 0.21 replaces the single-lane D3D12 authorization shape with
`fluidruntime-native-transfer-v1`. The exercised topology is:

| Field | Value |
| --- | ---: |
| Backend / operation | D3D12 (`2`) / copy buffer (`2`) |
| COPY queues | 1 |
| Command-list execution scopes | 2 |
| UPLOAD sources / DEFAULT destinations | 2 / 2 |
| `(scope,destination)` lanes | 2 |
| Registered fences | 1 |
| Signed runtime event budget | 145 |
| Buffer bytes per lane | 4,194,304 |
| CPU source snapshot / retained lane capacity | 16,777,216 / 8,388,608 bytes |
| Candidate action budget | 128 |

Each baseline run forwarded 136 tracked `CopyBufferRegion` calls. Each optimized
run forwarded eight required copies and skipped 128 exact duplicates, accounting
for 536,870,912 logical API bytes. Both final readbacks matched their expected
patterns. These are logical commands, not measured PCIe or physical RAM/VRAM
traffic.

## Correctness Gates

- The Gateway authorization context includes the exact topology, target/hook
  SHA-256, peer identity, pair/phase, action bit, and budget.
- D3D12 authorization without explicit topology is rejected.
- Invalid attach topology returns `E_INVALIDARG` before any vtable write.
- Complete registration is required before policy acceptance. A missing fence
  produces one rejected policy, zero skips, and complete rollback.
- One destination may have only one lane owner. A second scope attempting to
  register the same destination is rejected with zero skips and complete
  rollback.
- Each lane has independent retained bytes and generation. The transition,
  automatic invalidation, explicit invalidation, and close sequence ends at
  generation 7 in both lanes.
- `ExecuteCommandLists` records both registered scopes in order; `Signal`
  records logical fence ID 501 and value 1.
- The transfer ring namespace and header both carry backend ID `2`; managed
  code rejects any namespace/header mismatch.
- Baseline emits 144 events and optimized emits 145, with zero sequence loss or
  ring overrun. Every v2 event carries `generalized_transfer` flag 512.
- Five command-list slots and two queue slots are restored atomically on detach.
- Full readback, immutable CPU-shadow hashes, fence completion, target JSON,
  native snapshot, ring events, and managed report must agree.
- Native CTest passed 21/21 in Release and 21/21 in Debug; Debug targets fail on
  any D3D12 warning, error, or corruption message.

## RX 580 Measurement

Adapter: AMD Radeon RX 580 2048SP, vendor `0x1002`, device `0x6fdf`, LUID
`000000000000ea24`. The run contains one warmup and 30 measured alternating
baseline/optimized pairs at 128 candidates.

| Paired delta | p50 | p95 | p99 | Optimized wins |
| --- | ---: | ---: | ---: | ---: |
| Submit to fence | -45,816.500 us | -42,615.850 us | -37,080.440 us | 30/30 |
| COPY-queue GPU timestamp | -46,870.000 us | -42,814.100 us | -38,003.560 us | 30/30 |
| Managed decision to verified completion | -15,615.000 us | +18,261.950 us | +53,557.120 us | 27/30 |

Authorization latency p50/p95/p99 was 24,662 / 31,599 / 113,782.5 us across
31 authorizations and 310 round trips. Therefore:

- `native_execution_gate_passed=true`;
- `performance_claim_allowed=false`;
- blocker: `managed-end-to-end-improvement-not-consistent`.

The native path improved consistently in this owned workload. The complete
Gateway-to-effect product path did not pass its tail gate, so v0.21 does not
claim end-to-end acceleration.

## WARP And Fault Controls

Two WARP pairs passed the same content, topology, event, fence, and rollback
contract. WARP remains functional evidence only and is blocked by
`software-adapter-not-hardware` and `insufficient-paired-samples`.

Malformed, stalled, and cumulatively slow FluidLink peers were tested on WARP
and RX 580. Every case published no native policy and completed the 136-call
all-forwarded baseline with zero skips. The slow peer completed four round
trips before the 1,200 ms total deadline, proving mid-sequence fail-closed
behavior rather than only connection timeout.

```powershell
  -TrialPairs 30 -WarmupPairs 1 -Hardware $true
```

reduction, or unified-memory behavior. The result applies only to the owned,
cooperative D3D12 buffer workload and its exact frozen binaries.
