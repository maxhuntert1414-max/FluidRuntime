# v0.6 Copy-Elision Evidence

Captured on 2026-07-12 with the final v0.6 implementation. The measured workload
is the owned deterministic D3D11 target; these results do not establish a game
FPS improvement or support for third-party processes.

## Hardware Run

- Adapter: AMD Radeon RX 580 2048SP
- Vendor/device: `0x1002` / `0x6FDF`
- Adapter LUID: `000000000000cd6c`
- Trial design: 1 excluded warmup pair and 10 measured pairs
- Order: baseline-first on even pairs, optimized-first on odd pairs
- Correctness: content equivalent and rollback restored in every run
- Intervention: one 4,096-byte redundant `CopyResource` skipped per optimized run
- GPU timing: valid, non-disjoint timestamps in 10/10 measured pairs
- CPU paired delta: p50 `+29.05 us`, p95 `+521.62 us`; optimized lower in 4/10
- GPU paired delta: p50 `-1.76 us`, p95 `-1.352 us`; optimized lower in 10/10
- Claim scope: `owned-d3d11-copy-workload-only`

The CPU result is mixed and is not evidence of a CPU improvement. The GPU result
is consistent inside this controlled workload, but it remains a microbenchmark
result and must not be generalized to games.

## Reproduction

```powershell
dotnet run --project src/FluidRuntime -c Release -- copy-elision-lab `
  --target native/build/Release/fluidruntime-hook-target.exe `
  --hook native/build/Release/fluidruntime-present-hook.dll `
  --frames 300 `
  --hold-ms 1 `
  --gpu-timeout-ms 1000 `
  --trial-pairs 10 `
  --warmup-pairs 1 `
  --hardware true `
  --out artifacts/copy-elision-trace.json
```

Results are expected to vary with adapter, driver, clocks, power state, and host
load. Preserve the raw per-pair output, including negative results.
