# FluidLink Operation Batch Evidence v0.17.0

Recorded on 2026-08-02 between FluidRuntime 0.17.0, FluidLink 0.3.0, and
FluidGateway 0.65.0.

## Scope

This release changes the shape of one owned D3D11 authorization flow. It does
not add a new native action. The seed upload and 64 homogeneous candidate
uploads cross FluidLink as one batch template; the Gateway returns one ordered,
explicit 65-entry decision vector. The existing native content, generation,
budget, expiration, process-binding, and rollback checks remain mandatory.

The optional profile is identified by:

- contract SHA-256:
  `bf8727c22ac878ceff6dd0f462d6db5e81174737e839ecdf2e263a6f55268542`;
- golden-vector SHA-256:
  `9a626d9b257dd7341a090a49ca649bbc88c0c3ba32ba1edabbf18166a321aeea`;
- capability bit 7, event opcode 105, decision opcode 7;
- 1..256 operations and a nonzero 16-byte batch identity.

The original FluidLink v2 contract and capability mask are unchanged.

## Protocol Result

The comparison uses one authorization from the committed v0.15 WARP trace and
one authorization from the v0.17 WARP trace. FluidLink frame counters include
the complete application frames handed to TCP and exclude TCP/IP overhead.

| Per authorization | v0.15 serial | v0.17 batch | Change |
| --- | ---: | ---: | ---: |
| Logical runtime events | 71 | 71 | unchanged |
| Candidate decisions | 64 | 64 | unchanged |
| Round trips | 74 | 10 | -86.49% |
| Frame bytes sent | 21,285 | 1,168 | -20,117 |
| Frame bytes received | 5,471 | 1,970 | -3,501 |
| Total frame bytes | 26,756 | 3,138 | -88.27% |

This is an exact protocol-shape reduction across two versioned traces, not a
simultaneous latency benchmark. Authorization latency is deliberately excluded
from the comparison.

## Evidence Boundary

The WARP gate blocks a performance claim because it has only two pairs, uses a
software adapter, and measures Gateway authorization outside the native timing
window. Logical avoided bytes are API-level workload bytes, not measured
physical RAM-to-VRAM, VRAM-to-RAM, or PCIe traffic. This evidence does not claim
FPS, game latency, power, external-process support, or a general scheduler.
