# Owned D3D12 Transfer Observation Evidence v0.16.0

Recorded on 2026-08-01 with FluidRuntime 0.16.0.

## Scope

This milestone adds the first D3D12-native backend without attaching to another
application. A separate owned executable creates one deterministic 4 MiB
upload/default/readback buffer path, submits it to a COPY queue, waits on a
fence, verifies every byte, and reports the declared resource and
synchronization contract.

This is observation infrastructure, not D3D12 optimization. It does not hook or
inject into a game, skip a command, change residency, control a driver, measure
physical RAM/VRAM or PCIe traffic, or support a performance claim.

## Transfer Contract

Each native run performs:

1. select WARP or one high-performance hardware adapter and create a D3D12
   device at minimum feature level 11_0;
2. record adapter identity, UMA/cache-coherent UMA, resource heap tier, and
   process-scoped local/non-local `IDXGIAdapter3::QueryVideoMemoryInfo`
   snapshots;
3. create 4 MiB committed UPLOAD, DEFAULT, and READBACK buffers;
4. write a deterministic CPU pattern to the UPLOAD heap;
5. copy UPLOAD to DEFAULT, transition DEFAULT from the promoted `COPY_DEST`
   state to `COPY_SOURCE`, then copy DEFAULT to READBACK;
6. execute one COPY command list, signal fence value 1, and wait with a bounded
   deadline;
7. compare all 4 MiB with `memcmp`; FNV-1a hashes only label the evidence.

The DEFAULT buffer starts in `COMMON`. Its first copy-destination access uses
free implicit promotion, the only explicit barrier prepares the second copy,
and the buffer is expected to decay to `COMMON` after execution. This removed a
Debug Layer warning caused by requesting an initial state that buffers do not
retain. The final Debug run records zero warnings and zero errors.

The managed command holds the target executable without write/delete sharing,
records its SHA-256 before launch, verifies it again after all runs, and rejects
any native report whose PID differs from the process it launched. Missing or
unknown JSON fields, adapter/architecture drift, incorrect heap/state/queue
facts, incomplete fences, non-identical content, or backwards timestamps fail
the lab closed.

## Result

| Target | Runs | CPU record p50 / p95 | Submit-to-fence p50 / p95 | Total p50 / p95 |
| --- | ---: | ---: | ---: | ---: |
| WARP Release | 5/5 | 79.600 / 105.820 us | 9,692.400 / 10,738.920 us | 9,799.400 / 10,840.520 us |
| WARP Debug Layer | 5/5 | 141.600 / 152.500 us | 9,786.000 / 10,055.820 us | 9,964.500 / 10,243.920 us |
| AMD Radeon RX 580 2048SP | 10/10 | 52.850 / 59.595 us | 2,763.050 / 2,887.370 us | 2,848.800 / 2,964.385 us |

Release target SHA-256:
`42e2c8b0372c9825790275206f556b8b46137add179046c38c9bdd39a28efb9f`.
Debug target SHA-256:
`6e82eb3717177bf1bf9008103e2a7518e82cc93f1fcdd93bf4acba671f8499f9`.

All 20 runs completed the fence, preserved the exact 4 MiB payload, retained a
stable adapter identity within each report, and recorded 4 MiB logical upload
plus 4 MiB logical readback per run. The RX 580 reported vendor/device
`0x1002` / `0x6fdf`, LUID `000000000000e28d`, `UMA=false`, and resource heap
tier 2. Debug WARP ran with message validation available and recorded 0 warnings
and 0 errors.

The timings cover command recording and CPU submit-to-fence wait inside this
owned workload. They are not GPU busy time and are not compared against an
optimized alternative. Every report therefore sets
`performance_claim_allowed=false` with blockers
`observation-only-no-comparable-baseline` and
`logical-copy-bytes-not-physical-traffic`.

DXGI budget/current-usage values are process-scoped snapshots. Their deltas may
include allocation and driver accounting and must not be interpreted as bytes
physically transferred over PCIe or between RAM and VRAM.

## Reproduce

```powershell
cmake -S native -B native/build -A x64
cmake --build native/build --config Release

dotnet run --project src/FluidRuntime -c Release -- d3d12-observe-lab `
  --target native/build/Release/fluidruntime-d3d12-observation.exe `
  --runs 5 --gpu-timeout-ms 10000 --process-timeout-ms 20000 `
  --hardware false --out artifacts/d3d12-observation.json
```
