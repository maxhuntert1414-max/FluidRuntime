# v0.7.1 Automatic Destruction Evidence

Captured on 2026-07-12 with the final v0.7.1 implementation. This slice tests
automatic resource destruction only in the owned D3D11 target and only through
the same Buffer/Texture2D interface identity returned by the observed creation
call. It does not establish external-process safety.

## Contract

- Automatic lifetime tracking is opt-in through `FluidHookAttachEx`.
- Normal `FluidHookAttach` installs no Release hooks.
- Dynamic Release slots retain one mandatory original function per vtable.
- FluidRuntime holds no internal mutex while calling the original Release.
- A zero Release test result removes active state, invalidates dependent copy
  provenance, and records the pointer in bounded reuse history.
- Detach restores every fixed and dynamic slot before DLL unload.
- Missing originals, invalid lifecycle transitions, provenance failures, event
  loss, or rollback failures reject the run.

The COM return count is used only as owned-lab evidence. Microsoft documents it
as a test-purpose value, while requiring a zero count to free the final interface
reference: [IUnknown::Release](https://learn.microsoft.com/en-us/windows/win32/api/unknwn/nf-unknwn-iunknown-release).

## Concurrent Detach Stress

Five consecutive WARP stress runs detached the hook while another thread was
continuously creating and destroying buffers. Every run restored rollback and
returned successful attach/detach HRESULTs; detach completed after 77 to 145
worker cycles. The published representative trace completed 140 cycles.
Its pre-detach snapshot also confirmed one installed Release slot and zero
Release-hook or provenance failures while the worker was still active.

Report: [concurrent-detach-warp-v0.7.1.json](traces/concurrent-detach-warp-v0.7.1.json)

The positive-performance gate was **blocked** by

## Reproduction

```powershell
dotnet run --project src/FluidRuntime -c Release -- hook-lab `
  --target native/build/Release/fluidruntime-hook-target.exe `
  --hook native/build/Release/fluidruntime-present-hook.dll `
  --frames 120 `
  --hold-ms 500 `
  --gpu-timeout-ms 1000 `
  --hardware false `
  --out artifacts/automatic-destruction.json
```

Destruction through queried aliases, views, or unrelated COM interfaces remains
outside this evidence boundary.
