# FluidRuntime v0.21.1 Local-Use Hardening

Recorded on 2026-08-14 against the v0.21.1 release worktree. This is operational
and safety evidence, not a new performance result.

## Changes

- One verified cleanup path now owns all native subprocess termination. Normal
  exit, cancellation, timeout, and exit/kill races cannot silently leave a lab
  target running.
- The read-only native probe has an explicit deadline. CLI sampling intervals
  are capped at 60 seconds and probe deadlines at 120 seconds.
- Managed JSON evidence is flushed to a same-directory temporary file and moved
  over the final path only after completion. Cancellation preserves the prior
  report.
- Native builds use `/WX`, `/GS`, `/sdl`, `/guard:cf`, `DYNAMICBASE`,
  `NXCOMPAT`, and `HIGHENTROPYVA`.
- Explicit vtable null checks close the transfer-hook analyzer path. Large owned
  D3D11 fixture buffers moved from stack to bounded heap vectors.

## Verification

- Managed tests: 194/194 passed in Release.
- Native CTests: 21/21 passed in Release and 21/21 in Debug.
- AddressSanitizer CTests: 21/21 passed in Release with fail-fast settings and
  no reported memory violation. The ASAN runtime directory was supplied only
  to the instrumented test process and was not installed system-wide.
- Normal Release and Debug outputs are not ASAN-instrumented and do not depend
  on `clang_rt.asan_dynamic-x86_64.dll`; `build-asan` is developer-only.
- `dotnet build -c Release --no-restore -warnaserror`: zero warnings and errors.
- MSVC code analysis rebuilt `fluidruntime-d3d12-transfer-hook` and
  `fluidruntime-hook-target` with warnings treated as errors: both passed.
- Process cleanup is integration-tested with a live long-running owned child;
  repeated termination is complete and idempotent.
- Cancelled and failed atomic report replacements preserve the previous
  complete report and remove their temporary files.
- Cross-process FluidLink verification passed 11/11 v1 and 11/11 v2 round
  trips, including heartbeat and correlation checks.
- The local doctor passed offline diagnostics, exclusive FluidLink binding,
  managed Runtime discovery, and all eight native PE assets. PresentMon was not
  installed, so live capture remained unavailable.
- RX 580 smoke gates passed two owned D3D12 transfer pairs and two owned D3D11
  direct-update pairs. Each controlled run omitted exactly 128 equivalent 4 MiB
  calls. Malformed, stalled, and slow peers produced all-forwarded baselines
  with zero skips. Two pairs are functional smoke evidence, not a statistical
  performance gate; both reports keep `performance_claim_allowed=false`.

## Boundary

The D3D11 and D3D12 contract mode identifiers remain at v0.12.0 and v0.21.0
because this patch does not change their wire or evidence schemas. Vulkan and
external-process hooking remain unimplemented. No product-level performance,
FPS, power, PCIe, or physical-residency claim is added by this release.
